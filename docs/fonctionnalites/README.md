## Mode d'utilisation

Chaque fiche sert a documenter :

- le besoin fonctionnel
- l'etat actuel de l'implementation
- les attendus
- les donnees et contraintes techniques
- les pistes d'evolution
- le suivi

Quand une fonctionnalite evolue, il faut mettre a jour :

1. la fiche concernee
2. le [suivi des fonctionnalites](C:/Users/Mathis%20Trunet/Documents/GitHub/StudioParcellaire/docs/SUIVI_FONCTIONNALITES.md)
3. si necessaire, le [cahier des charges](C:/Users/Mathis%20Trunet/Documents/GitHub/StudioParcellaire/docs/CAHIER_DES_CHARGES_Studio_Parcellaire.md)
